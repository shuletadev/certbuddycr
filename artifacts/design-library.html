Aesthetic Philosophies

Eight named visual systems — typography, color, layout, motion, and detail treatment all defined together. Name one directly, or describe a vibe and it maps to the closest match. designer-skills:frontend-design

AES·01
Dieter Rams
(Functionalist)
Less but better
Suisse Intl / Helvetica NeueDesign
Type
Clean sans (Helvetica Neue, Suisse Intl), tight heading tracking, one strict scale.
Color
Near-monochrome, single functional accent. White/light-grey ground.
Layout
Strict grid. No asymmetry for its own sake.
Spacing
4/8px mathematical scale, generous padding.
Motion
Minimal — purposeful state changes only.
Details
Subtle borders over shadows. Sparing rounded corners.
AES·02
Swiss / International Typographic
The grid is sacred
Neue Haas Grotesk / UniversDesign
Type
Strong sans (Neue Haas Grotesk, Univers). Dramatic scale contrast, all-caps subheads.
Color
High contrast — black, white, one bold primary as color blocks.
Layout
Rigid multi-column grid. Alignment is non-negotiable.
Spacing
Defined by the grid module — gutters are part of the design.
Motion
Grid-respecting transitions and scroll reveals. No bounce.
Details
Rule lines as structure. No gradients, no shadows.
AES·03
Japanese Minimalism
(Ma)
Negative space is content
Cormorant / Noto Sansdesign
Type
Thin sans or elegant serif. Line-height 1.8–2.0, small body, large margins.
Color
Muted naturals — warm greys, stone, sage. Near-monochrome.
Layout
Asymmetric but balanced. Content floats in large empty areas.
Spacing
Extreme whitespace — 2–3x what feels normal.
Motion
Slow gentle fades (400–600ms). Opacity over position.
Details
Hairline borders. Subtle paper/linen texture, soft diffused shadows.
AES·04
Brutalist / Raw
Anti-aesthetic is the aesthetic
JetBrains Monodesign_
Type
System fonts, monospace, or aggressive display faces. Mixed sizes.
Color
Black/white primary. If color: raw, clashing (hazard yellow/orange).
Layout
Visible borders, exposed box model, stacked blocks, deliberate roughness.
Spacing
Tight or intentionally uneven.
Motion
None, or jarring hard cuts.
Details
Visible outlines. Default form elements can be intentional.
AES·05
Scandinavian
Warmth plus restraint
Nunito / PoppinsDesign
Type
Rounded friendly sans (Nunito, Poppins, Circular). Medium weights.
Color
Warm whites, soft blues, muted greens, clay. Charcoal, never pure black.
Layout
Clean, open, card-based. Rounded corners (8–12px).
Spacing
Generous but not extreme.
Motion
Gentle natural easing. Subtle hover lifts.
Details
Soft low-opacity shadows. Illustration-friendly.
AES·06
Art Deco / Geometric
Bold symmetry, statement and luxury
Futura / Poiret OneDesign
Type
Geometric display (Futura, Poiret One). All-caps headlines, extreme tracking, serif body.
Color
Gold/champagne, emerald, navy, burgundy, black. Metallic accents.
Layout
Symmetrical, centered, strong vertical axis, decorative frames.
Spacing
Structured, architectural.
Motion
Elegant staggered reveals, parallax depth.
Details
Geometric patterns, ornamental borders, marble/metal texture.
AES·07
Neo-Memphis
Playful chaos
clashing weightsDesign!
Type
Clashing weights/styles on purpose. Oversized headlines, angled text.
Color
Bold primaries and neons, clashing combos. Flat color, no gradients.
Layout
Broken grid, overlapping elements, shapes as compositional pieces.
Spacing
Irregular rhythm — dense in places, empty in others.
Motion
Bouncy, exaggerated hover effects.
Details
Thick borders, dot/dash/zigzag patterns, hard bright drop shadows.
AES·08
Editorial / Magazine
Typography does the heavy lifting
Playfair / FrauncesDesign
Type
Display serif headlines (Playfair, Fraunces), clean sans body. 72–120px heroes.
Color
Minimal — black/white with one editorial accent.
Layout
3–5 column grid, full-bleed images, mixed column widths.
Spacing
Generous margins, tight heading leading, open body leading.
Motion
Scroll-triggered reveals, parallax on images.
Details
Thin rule dividers, caption type, print-inspired metadata.
AES·00
Process layer — pairs with any philosophy above
Anthropic's official frontend-design plugin
Ground it
Identify the real subject, audience, and job before designing — distinctive choices come from the subject's own materials and vernacular.
Two-pass
Sketch a compact token plan (4–6 hex colors, type roles, layout concept) → review it against the brief and revise anything generic → then write code.
Avoid
The 5 recognizable AI tells: warm-cream + terracotta serif; near-black + acid-green; broadsheet hairline columns; identical rounded SaaS cards with one shadow; ALL-CAPS eyebrow/middle-dot/em-dash template chrome.
Restraint
Spend boldness in one place. Responsive, visible focus states, reduced-motion respected, by default.

Number counter≈ REF·13
click "count up"
Mirrors Kinetics' actual "Number Counter" demo: digits bump and overshoot past the target before settling.
view code 
function animateCount(el, target) {
  const overshoot = Math.round(target * 1.12) + 3;
  let start;
  function up(ts) {
    if (!start) start = ts;
    const p = Math.min((ts - start) / 450, 1);
    el.textContent = Math.round(p * overshoot);
    if (p < 1) requestAnimationFrame(up); else settle();
  }
  function settle() {
    let s2;
    function down(ts) {
      if (!s2) s2 = ts;
      const p = Math.min((ts - s2) / 220, 1);
      el.textContent = Math.round(overshoot - p * (overshoot - target));
      if (p < 1) requestAnimationFrame(down); else el.textContent = target;
    }
    requestAnimationFrame(down);
  }
  requestAnimationFrame(up);
}

stage.addEventListener('mousemove', (e) => {
  const r = btn.getBoundingClientRect();
  const cx = r.left + r.width / 2, cy = r.top + r.height / 2;
  const dx = e.clientX - cx, dy = e.clientY - cy;
  const dist = Math.hypot(dx, dy), radius = 90;
  if (dist < radius) {
    const pull = (1 - dist / radius) * 14;
    const angle = Math.atan2(dy, dx);
    btn.style.transform =

    Interrogate for audience, constraints, and a real reference aesthetic instead of guessing. No file output. Skip if you already have a clear idea.

    Document intent → DESIGN_BRIEF.md.
  3. Information Architecture

    Navigation, page structure, user flows → INFORMATION_ARCHITECTURE.md. Skip for a single component.

    /design-tokens
    Lock a concrete palette/type/spacing system from the brief's philosophy → tokens file. Skip if tokens already exist.

    /brief-to-tasks
